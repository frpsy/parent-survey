# 학부모 조사함

채아 학년과 씨앗별 학부모 단톡방에서 하는 조사(김밥 주문, 저녁 모임 참석, 야유회 참석 인원 등)를 한곳에서 만들고 집계하는 웹페이지입니다.

## 할 수 있는 일

- 모임별(채아 학년 / 씨앗별) 탭으로 조사를 나눠 관리
- 양식으로 바로 만들기: 김밥 주문, 저녁 모임 참석, 야유회 참석 인원, 빈 양식
- 질문 형식: 참석 여부(인원 포함 가능), 품목별 수량(가격 합계 자동), 숫자, 하나 고르기, 여러 개 고르기, 자유 입력
- 응답자는 링크만 열고 이름과 답을 입력. 같은 기기에서 다시 열면 수정·취소 가능
- 관리자 화면: 실시간 집계, 이름 가나다순 정리, 카톡 공지 복사, 결과 요약 복사, 엑셀(CSV) 받기, 마감/다시 열기, 복제, 응답 삭제
- 마감 시각이 지나면 응답이 자동으로 막힘(화면과 서버 규칙 모두)

## 문안 붙여넣기로 조사 만들기

관리자 화면의 "문안 붙여넣기로 만들기"에 아래 형식의 글을 붙이면 질문까지 한 번에 채워집니다. 채팅에서 "김밥 조사 만들어줘"라고 하면 이 형식으로 문안을 받을 수 있습니다. 결과 화면의 "문안 복사"로 기존 조사를 같은 형식으로 꺼낼 수도 있습니다.

```
모임: 2학년              (2학년 또는 씨앗별, 없으면 지금 탭)
제목: 소풍 김밥 주문
안내: 소풍날 아침에 받습니다.   (다음 줄까지 이어 쓸 수 있음)
마감: 2026-11-04 21:00   (한국 시간, 없으면 "없음")
결과공개: 아니오          (예: 응답자에게 집계 공개)
질문: 품목 | 김밥 종류별 수량 | 필수 | 단위=줄
- 야채김밥 | 3000        (가격은 선택)
- 유부김밥 | 3500
질문: 참석 | 참석 여부 | 필수 | 인원   (인원: 함께 오는 인원도 받기)
질문: 하나 | 받는 곳
- 학교 정문
- 소풍 장소
질문: 여러개 | 가능한 날짜
- 11/14(토)
질문: 숫자 | 필요한 의자 수 | 선택 | 단위=개
질문: 글 | 요청 사항 | 선택
```

질문 형식: 참석, 품목, 숫자, 하나, 여러개, 글. 옵션: 필수(기본)/선택, 인원, 단위=…

## 화면

| 파일 | 용도 |

| `index.html` | 학부모용 조사 목록 (모임 탭) |

## 지금 상태: 체험 모드

`js/config.js` 의 Firebase 값이 비어 있으면 체험 모드로 동작합니다. 모든 기능을 써 볼 수 있지만 응답이 그 기기 브라우저에만 저장되어 다른 학부모와 공유되지 않습니다.

## 실제 운영 설정 (한 번만)

무료 요금제(Spark)로 충분합니다.

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트를 만듭니다. (Google Analytics는 꺼도 됩니다)
2. 빌드 > Firestore Database > 데이터베이스 만들기. 위치는 `asia-northeast3 (서울)`, 프로덕션 모드로 시작합니다.
3. 빌드 > Authentication > 시작하기 > 로그인 방법에서 **익명**과 **Google**을 사용 설정합니다.
4. Authentication > 설정 > 승인된 도메인에 `frpsy.github.io` 를 추가합니다.
5. 프로젝트 설정 > 내 앱 > 웹 앱(</>) 추가 후 나오는 `firebaseConfig` 값을 `js/config.js` 에 붙여 넣습니다. (이 값은 공개되어도 되는 식별 정보이며, 데이터 보호는 보안 규칙이 담당합니다)
6. `js/config.js` 의 `adminEmails` 에 관리자 구글 계정을 넣습니다.
7. `firestore.rules` 의 `YOUR_EMAIL@gmail.com` 을 같은 계정으로 바꾼 뒤, 전체 내용을 Firestore > 규칙 탭에 붙여 넣고 게시합니다.
8. 저장소 Settings > Pages > Source 를 **GitHub Actions** 로 바꿉니다. main 에 반영되면 테스트 후 자동 배포됩니다.

배포 주소: `https://frpsy.github.io/parent-survey/`

## 보안·개인정보

- 조사 목록과 질문은 링크를 아는 누구나 볼 수 있습니다. 검색엔진 노출은 막아 두었습니다(`noindex`).
- 응답은 기본적으로 관리자만 전체를 봅니다. 조사를 만들 때 "응답자에게 집계와 이름 공개"를 켜면 응답 화면에 집계가 보입니다.
- 이름은 "채아아빠"처럼 최소한으로만 받고, 전화번호·주소 같은 정보는 질문으로 넣지 않는 것을 권합니다.
- 응답자는 익명 로그인으로 구분되어 자기 응답만 쓰고 고칠 수 있습니다.

## 개발

```bash
npm test          # 집계·검증 로직 단위 테스트 (Node 20+)
npm start         # http://localhost:8080 에서 체험 모드로 확인
```

모임을 추가하거나 이름을 바꾸려면 `js/config.js` 의 `groups` 를 고칩니다. 이미 만든 조사의 모임 id는 바꾸지 않습니다.
